# To make branch
```sh
git branch BRANCHNAME
```
### Example
```sh
git branch feature/auth
```
---
# To switch branch
```sh
git checkout BRANCHNAME
```
### Example
```sh
git checkout main
```
---
# To push your local branch to remote repository (github)
```sh
git push origin BRANCHNAME
```
### Example
```sh
git push origin feature/auth
```
---
# To pull your remote branch from github, to your local PC
```sh
git pull origin BRANCHNAME
```
### Example
```sh
git pull origin main
```
---
